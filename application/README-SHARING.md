# MineOS Mobile Application

## Run locally

1. Extract this folder.
2. Create `.env` by copying `.env.example`.
3. Set `EXPO_PUBLIC_API_URL` to the LAN IP address of the computer running the MineOS backend.
4. Install dependencies with `npm install`.
5. Start Expo with `npx expo start`.

Do not share a real `.env` file because it may contain environment-specific URLs or credentials.
